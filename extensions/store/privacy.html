Privacy Policy — chrome-use

Chrome extension (id knfcmbamhjmaonkfnjhldjedeobeafmk) · Last updated 2026-10-13

The extension has no analytics or tracking backend. It communicates with the locally installed chrome-use CLI through Chrome native messaging. It handles browser observations and automation commands requested by the user. In the agent side panel, the selected local Codex, Claude Code, OpenCode or Pi CLI may send the user's task and requested browser context to its configured model service. That service's terms and privacy policy apply.

Local agent conversations

The side panel sends tasks to a local agent service through the native host. Conversation messages, replies and tool results are saved in a profile-scoped journal on the user's computer. The native service uses authenticated loopback IPC; the extension itself does not contact a model server. Chrome local storage keeps selection and message identifiers, not the conversation text. The panel does not ask you for an agent API key. Existing CLI authentication and provider configuration remain with the chosen CLI; discovery does not return credential values.

The current-page tag includes the active webpage's title, URL and tab identifier with the next message unless removed with ×. Page observations requested by the agent may also become model context. The model menu comes from CLI metadata; a custom model ID selects a model through that CLI.

Permissions depend on the agent: Codex/Claude use approval prompts or full access; OpenCode keeps CLI permission rules and can allow tools without asking; Pi exposes only chrome_use MCP tools in Browser only mode and its full tool set with full access. Full access automatically answers supported permission requests; it does not prevent task or page context from reaching the configured model service.

Deleting a stopped conversation removes its local panel history and browser session, plus Codex rollout files, Claude session files/directories, OpenCode history through session/delete, or Pi session files in the conversation folder. Codex's SQLite cache is not modified. Cleanup failures and unconfirmed browser-tab closure are reported.

Data handling

DataPurpose and destination
Profile emailRead locally to label the connected Chrome profile and sent to the local native host. It is not used for advertising or analytics.
Task messages, replies and requested webpage contentUsed to perform the user's browser task. The local agent may transmit task context to its configured model service. Messages and tool returns may be retained in the local conversation journal.
Target URLs and automation actionsUsed to identify the intended page, execute requested actions and report their effects. Task-related URLs and tool returns may appear in local history or agent context. The extension does not harvest general browsing history or monitor unrelated user activity.
Cookies and authentication informationCookie commands read or write the targeted site's cookies only when requested through the local CLI. The extension does not export cookies on its own or send them to a developer-operated server. The user's downstream CLI or agent controls any further handling.
Configuration and credentialsDiscovery reads installation/configuration evidence. Panel edits are limited to supported model/provider fields. Credential values are not returned by configuration discovery or stored in the panel. The chosen CLI manages its own login.

notificationsSurface local status/error notices (e.g. connection lost) to the user. No data leaves the device.

Data sharing and limited use

We do not receive task contents through an extension-operated server and do not sell data or use it for advertising, credit decisions or unrelated purposes. Data accessed through the extension is used only for its browser-automation features requested by the user. A model service selected through the local CLI may receive the task context needed to perform that feature. Our use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.
