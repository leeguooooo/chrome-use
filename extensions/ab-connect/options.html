Stealth mode
On by default. chrome-use then adds nothing of its own to a page: no overlay, no page globals, real input events. Turn it off to use features that draw into pages, such as the agent cursor. Inspect & Ask still works either way, since you start it yourself.

Notifications

A gentle heads-up when the bridge connects or drops, or a panel task finishes.

Connection notifications
Notify me when chrome-use links to or unlinks from Chrome.
Notify when a task finishes
When a side-panel task finishes, fails, stops or waits for your approval, show a notification and a count on the toolbar icon. Nothing is shown for the conversation the panel already has open in the focused window.

Side-panel agent

Agent works in
This tab: a conversation in a tab's side panel works in that tab with your logins (it shows an AI badge, and you can take it back). Its own window: the agent opens its own tabs in a separate window. Each conversation can change this.

Inspect & Ask

Press the shortcut and click elements: they go into this tab's side-panel chat, or, on a site set to Terminal session, to the coding session working on that project (via ocs) with their source location and a screenshot.

Allow sending to terminal sessions (ocs)
Off by default. Adding elements to the side-panel chat needs no setup; this switch is for sending them to a terminal session over ocs. Nothing is injected into pages until you press the shortcut (Alt+Shift+C) or the popup button. Change the shortcut
Allow element picking on all sites
Chrome asks once, instead of the first time you pick an element on each site. The extension still touches a page only when you pick an element there.

The “started debugging this browser” bar

chrome-use drives Chrome via the DevTools protocol, so Chrome shows that bar while an agent is driving a tab. Automatic debugger release is disabled by default (0 seconds). Set “Release idle tabs after” to a positive timeout to release idle tabs between tasks. A one-time restart with a startup flag removes it entirely (your tabs & logins are restored automatically).

Release idle tabs after
Seconds without agent activity before the debugger detaches from a tab (the bar goes away). The next command re-attaches automatically. 0 keeps tabs attached until the session ends.
