chrome-use · 安装 · 已登录浏览器指南 · MCP · 选型

让 Codex 或 Claude Code 操作已登录 Chrome

chrome-use 是开源 CLI 和 MCP 服务器，通过扩展和原生消息连接你正在使用的 Chrome，保留该配置文件的登录态。

安装和验证

curl -fsSL https://raw.githubusercontent.com/leeguooooo/chrome-use/main/install.sh | sh
chrome-use extension install
chrome-use doctor

按安装指南完成扩展安装。doctor 的诊断不能代替网站账号检查。

一个可复现的只读任务

chrome-use --session seo-example open https://github.com/leeguooooo/chrome-use
chrome-use --session seo-example snapshot -i
chrome-use --session seo-example get title

预期结果：打开仓库页，snapshot 返回页面元素，标题含 leeguooooo/chrome-use。无需发送消息或改变账号数据。

怎么接到 agent？

能运行 shell 的 Codex、Claude Code 用 CLI，先读 chrome-use skills get core；只能接 MCP 的客户端用 chrome-use mcp。

和 Playwright、browser-use 怎么选？

已有登录态、人工接管和多个 agent 共用浏览器是 chrome-use 的重点。Playwright 适合测试和编程自动化，也能连接已有浏览器。browser-use 提供 agent 框架。选型时比较实际连接路径，不能把其他工具一概当作空浏览器。

能保证没有验证码吗？

不能。指纹测试不等于网站放行。登录、验证码和二次验证由用户处理。
