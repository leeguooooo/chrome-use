v1.5.x

  • v1.5.178 (October 8, 2026): Requires extension ab-connect 0.5.30 (published; Chrome updates it automatically). chrome-use no longer pops up browsers or grabs your tabs: agent tabs stay in a background agent window, never your window; unit tests and doctor no longer launch visible browsers; screenshots, tab duplicate, state save and password-manager recovery no longer touch your foreground or tabs (a page pop-up after an agent click can still raise Chrome, #468) (#460). Over the relay a pop-up opened by the session's own tab is adopted by exact tab id, reported, followable and closed with the session; unconfirmed tabs are left alone (#457). ChooseBrowser rules are binding, with explicit errors when the profile isn't connected or the session is bound elsewhere (#466). find refuses ambiguous actions and lists candidates (#459). Also npm postinstall, an unused options card, skill frontmatter and env docs (#462–#467). Contributors: @AmeerAliAnwar, @leeguooooo.
  • v1.5.177 (October 8, 2026): --observe attaches its page-change watcher before the action, so an observed click no longer sits out a 500 ms window it had already missed; the settle rules are unchanged. On a three-page catalog task each click --observe went from ~740 ms to ~220 ms and the task from ~3.5 s to ~1.4 s (median of 6 alternating rounds vs 1.5.176; form and delayed-load tasks unchanged). --follow settles the opened tab on its own. Fixes: pick --observe observes; batch step flags apply to their step, an explicit false overrides, and a step --tab never overrides a command's own tab; screenshot <path> --selector in any order; a fill whose handle was lost is read back before any rewrite and an unreadable value writes nothing; openedTab is reported again without --follow (#455).
