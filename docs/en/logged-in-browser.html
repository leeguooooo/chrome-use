chrome-use · Install · Logged-in browser guide · MCP · Compare

Automate logged-in Chrome with Codex or Claude Code

chrome-use is an open-source CLI and MCP server that connects to your existing Chrome through an extension and native messaging, retaining that profile’s signed-in sessions.

Install and verify

curl -fsSL https://raw.githubusercontent.com/leeguooooo/chrome-use/main/install.sh | sh
chrome-use extension install
chrome-use doctor

Finish extension setup using the installation guide. A doctor result does not establish which website account is signed in.

A reproducible read-only task

chrome-use --session seo-example open https://github.com/leeguooooo/chrome-use
chrome-use --session seo-example snapshot -i
chrome-use --session seo-example get title

Expected: the repository opens, snapshot returns page elements, and the title contains leeguooooo/chrome-use. No messages are sent or account data changed.

How do agents connect?

Shell-capable Codex and Claude Code use the CLI and load chrome-use skills get core. MCP-only clients use chrome-use mcp.

How does it compare with Playwright or browser-use?

Existing sessions, human takeover and multiple agents sharing one browser are chrome-use’s focus. Playwright supports programmed tests and existing-browser connections. browser-use supplies an agent framework. Compare actual connection paths rather than assuming other tools always start empty browsers.

Does it guarantee no CAPTCHA?

No. Fingerprint measurements do not guarantee site acceptance. The user handles login, CAPTCHA and second-factor verification.
