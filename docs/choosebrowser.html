ChooseBrowser：每个站点，落在对的账号上

工作、个人、客户的账号各住一个 Chrome profile，你心里清楚哪个站点归谁。 ChooseBrowser 把这份清楚存下来：一个 macOS 链接路由器，每个 profile 一行， 规则可以精确到路径。装了它，chrome-use open 自动选对 profile，agent 再也不会在错的账号里干活。

先问再开

把它设为默认浏览器，之后从「邮件」「信息」、Slack 或任何 App 点出来的链接都会先弹一个紧凑的选择器， 列出这台 Mac 上装的所有浏览器和每一个 Chrome profile。点一下，或者按 ⌘1–⌘9，链接就开在那里。

按 ⌥↵ 记住一次，这个站点以后永远走那个浏览器。规则随时能看、能删。

为什么 chrome-use 用户会想要它

chrome-use 驱动的是你真实的、已登录的 Chrome。多个 profile 时，「用哪一个」原本要每次用 --browser 说一遍，说错了 agent 就在错的账号里操作。ChooseBrowser 装上之后， 这个决定变成一条你写过一次的规则：

规则替你选 
$ chrome-use open https://github.com/my-org/repo
· using Chrome profile Profile 14 — a ChooseBrowser rule routes this site there
  (github.com|/my-org*). Override with --browser <id|email>, or skip with --no-choosebrowser.

# 反过来：这次显式指定了 profile，顺手把规则写回去
$ chrome-use open https://github.com/my-org/repo --browser work@example.com --remember
· asked ChooseBrowser to route github.com to work@example.com from now on — confirm in its dialog.
🎯 agent 不再进错账号

规则是你写下的意图，排在「猜最近聚焦的窗口」之前。open 会说明选择来自哪条规则。

✍️ 写回也只要一个 flag

--remember 提议一条规则，ChooseBrowser 弹窗让你确认。没点确认，什么都不会存。

🙈 没装就完全无感

没有规则文件就不改变任何行为、不打任何提示。--no-choosebrowser 单次跳过。

🔍 doctor 认得它

chrome-use doctor 报告装的是哪个版本，以及规则是否可读。需要 ChooseBrowser 0.2.1 或更高。

它本身就是一个好用的浏览器选择器

👥 每个 Chrome profile 一行

一次本地设置后，Chrome、Edge、Brave、Vivaldi、Chromium 的每个 profile 都是选择器里独立的一项。工作、个人、客户账号各走各的。

🛤️ 同一网站，两个去向

规则可以匹配路径，不只看域名。github.com/my-org 走工作号，其余 GitHub 走个人号。

🧠 它会学

同一网站反复选同一个浏览器，它就排到最前，并显示原因。⌘1–⌘9 直接开，⌘C 只复制链接。

🔒 无账号、无跟踪、无统计

规则和偏好只在这台 Mac 上。想要多台同步，走你自己的 iCloud，可选。

它怎么工作

ChooseBrowser 注册为 http 和 https 链接的处理程序。在「系统设置 › 桌面与程序坞 › 默认网页浏览器」把它设为默认后， macOS 会把每个链接先交给它。它显示选择器，把链接交给你选中的浏览器，然后退出。 可以开启一个短倒计时，让它自动打开那个显而易见的选择，按任意键即可停下。 自动列出所有已安装浏览器；拖动排序即决定 ⌘1–⌘9 的顺序；不想出现的 App 可以隐藏，随时再显示。
