插件更新日志

ab-connect 是驱动你真实 Chrome 的浏览器扩展，通过原生消息和 CLI 通信。 它有独立于 CLI 的版本号（0.5.x）。 chrome-use extension status 会告诉你装的是哪个版本、商店发的是哪个版本。 0.5.23 起扩展会自己催 Chrome 检查更新，所以大多数用户无需手动升级。

📝 找 CLI 的版本？
这一页是扩展的历史。chrome-use 命令行本身的版本（1.5.x）在 CLI 更新日志。两者独立发布：扩展走 Chrome Web Store，CLI 走 GitHub Releases。

0.5.x

  • 0.5.25（2026-09-10）：一扇通用的门 ABExt.call —— CLI 想调 chrome.tabs / tabGroups / windows / downloads / webNavigation 的白名单方法时，不再需要发一个新扩展版本。 改动类调用只允许作用在 agent 自己创建的标签上（adopted 标签只读、windows.create/remove 不开、 debugger / identity / storage / runtime / management 永远不经这扇门）。新增 ABExt.state， 一次返回扩展持有、拥有与配置的全部状态。权限不变，升级不触发重新授权（#294）。
  • 0.5.24（2026-09-09）：tabs 报出中继实际附着的标签，而不只是会话请求的那个； 两者不一致时明确出声，避免把中继掉标签的情况误读成权限问题（#279）。
  • 0.5.23（2026-09-09）：自更新 —— 扩展主动请 Chrome 去商店查更新， 而不是等它自己的多小时排期；下载好的更新在没有标签附着时就地应用。不需要新权限； 一直找不到空隙的更新，会在 worker 停止时由 Chrome 应用（#272）。
  • 0.5.22（2026-09-09）：提高中继恢复、观察结果与连接状态的可信度。
  • 0.5.21（2026-09-08）：配合 session name 的标签组命名，任务开始、开标签之前先给会话起名（#236）。
  • 0.5.20（2026-09-04）：修复上传、select、idle 与中继的一批回归（#212）。
  • 0.5.19（2026-09-02）：修复 #201–#206（idle 分离、press/xpath、中文读回、点击移焦、cwd 会话、shadow-DOM 快照）。
  • 0.5.18（2026-08-30）：收敛中继、ref 与 macOS 泄漏问题；显式 open/navigate 遇到渲染器级 Page.navigate 超时时，通过浏览器级标签 API 恢复，保住同一会话和标签（#198）。
  • 0.5.17（2026-08-24）：上架包，权限说明补齐。
  • 0.5.16（2026-07-31）：修复录像、快照、find 与冻结标签的问题；tab inspect 的探测通道自此可用（#151 #154–#157）。
  • 0.5.14 – 0.5.15（2026-07-28）：修复开启中继、对话框、status 与站点适配器的问题，以及发版评审的跟进。
  • 0.5.13（2026-07-24）：原生下载与带版本的本地 HTTP API（#132）。
  • 0.5.12（2026-07-16）：默认把 agent 标签开在独立窗口里，加上更聪明的默认 profile 选择（#120）。
  • 0.5.10（2026-07-06）：popup 底部流量链接，静默原生宿主的 lastError。
  • 0.5.9（2026-07-02）：加 identity / identity.email 权限，让 hello 带上该 profile 的账号邮箱。
  • 0.5.8（2026-06-30）：穿透 OAuth GSI 登录 iframe（OOPIF），提前附着登录弹窗。
  • 0.5.7（2026-06-29）：通过 chrome.idle 在睡眠唤醒后重连中继（#72）。
  • 0.5.6（2026-06-29）：不再持久化 adopted 标签，清掉卡住的「正在调试此浏览器」横幅（#71）。
  • 0.5.5（2026-06-28）：只附着 agent 自己的标签，用户页面上不再出现调试横幅（#68）。
  • 0.5.4（2026-06-27）：对永远无法附着的标签停止重连风暴（#64）。
  • 0.5.3（2026-06-26）：hello 里报出中继正在驱动哪个 Chrome profile（#60）。
  • 0.5.2（2026-06-26）：主动 20 秒心跳，MV3 worker 不再空闲掉线中继（#59）。
  • 0.5.0 – 0.5.1（2026-06-24）：图标与 UX 翻新（友好图标、打磨的 popup、options 页、agent 光标），圆角透明图标。

0.4.x 与更早（早期历史）

0.4 系列是把中继做稳的一段：稳定的 per-tab 会话 id、跨进程分离后自动重连、 用稳定的 CDP targetId 恢复被换了 tabId 的会话、stale sessionId 时响亮失败而不是路由到随机标签、 以及 adopt 读取已有标签、按标签组 scope 的 Target.getTargets、默认空闲关闭 + keep。 再往前，0.1.0 – 0.3.0（2026-06-09）是奠基：从 openclaw-browser-relay 改写的 MV3 连接扩展、 零 token 的原生消息传输、以及通过 Chrome 配置 profile 强制安装（无需 Load-unpacked）。
