# chrome-use directory package

This directory is the source template for the OpenAI directory ZIP, not the assembled installable plugin. Run `sh packaging/openai/build.sh /absolute/output/path` from the repository to assemble it. The build adds the skill tree and helper files from repository sources.

See the [project README](https://github.com/leeguooooo/chrome-use#readme) for installation, supported clients and requirements. See [SECURITY.md](SECURITY.md) for reporting and security boundaries.
