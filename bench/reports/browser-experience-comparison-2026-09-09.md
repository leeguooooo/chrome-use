# chrome-use 与 Codex 内置浏览器：优化后体验对照

**chrome-use 在输出裁剪选项上更灵活；这轮补齐了操作前的价格信息、操作后的状态回执，并修复了几处会话与结果表达问题。现有对照支持部分场景追平，尚不足以证明整体可靠性超过 Codex。**

记录日期：2026-09-09。基础可靠性改进已随 v1.5.109 发布；新增交互观察与拖拽改进已合入 [PR #246](https://github.com/leeguooooo/chrome-use/pull/246)，进入 v1.5.111 发布构建。扩展 0.5.22 已打包验证，商店及日常连接仍为 0.5.21，上传待用户确认。

| 体验维度 | 当前判断 | 证据与限制 |
|---|---|---|
| 控制输出范围和大小 | chrome-use 选项更丰富 | 提供交互筛选、范围、深度、过滤、字节预算及续读。预算限制快照树，整个 JSON 还包含其他字段；超长单节点完整保留。 |
| 操作前的信息是否够用 | 商品样例已追平 | 候选首次观察保留商品价格和库存；内置 CUA 在同一合成页面的首次 AX 也直接提供这些信息。 |
| 操作后能否确认结果 | 状态回执样例已追平 | 两边都能在点击后的观察里看到 Cart: folder。chrome-use 原先会漏掉该静态回执。 |
| 出错后说明是否清楚 | chrome-use 的结果表达更明确 | 分开报告动作结果与 complete / partial / unavailable 观察质量，结果未知时不自动重放。没有对内置工具做同条件故障注入，不能据此宣布故障恢复率领先。 |
| 长流程真实任务完成率 | 不能判定整体胜负 | 新候选完成 SauceDemo，但浏览器配置与历史 Codex 基线不同。一次完成不能代表普遍稳定。 |
| 浏览器之外的操作 | Codex 集成范围更广 | 内置工具还提供原生应用操作；本次通过原生 Chrome 界面进入了浏览器接口未能打开的扩展后台。chrome-use 的当前对照范围是浏览器。 |

## 已验证的变化

- 商品上下文支持语义商品项、普通 div 分组、多层按钮、长描述及链接标题卡片。短字段优先，长文字明确截断，歧义分组不拼接。
- 同一链接卡片页面去重后，快照正文从 **747 字节降到 469 字节**，context 从 9 处降到 3 处。选购和回执验证仍通过。这是 chrome-use 候选之间的比较，不是与 Codex 的字节比率。
- 长描述页面按 200 字节树预算分段读取，可以逐行重建原快照，未重复或遗漏；续读得到的引用仍可操作。
- 动作已执行但观察捕获失败时，保留动作结果、报告观察不可用，并提示不要重放。下载的 v1.5.109 macOS ARM64 包通过三种提交路径的后台计数检查，每种只提交一次。
- iframe 展开不再依赖引用是最后一个属性；可点击 status 保留自身引用。拖拽方式依据当前连接，不受其他 profile 的 relay 存在与否影响。

## 对照与验证口径

内置 CUA 在普通 div 商品页用了 **2 次工具调用**：创建页面并观察；点击并观察回执。chrome-use 检查脚本用了 **3 条任务命令**，第三条是独立读回验收，前两条已经提供任务所需信息。CLI 命令数和 CUA 工具调用数不等价；一侧脚本、一侧 agent，也不构成严格模型耗时比较。

真实 SauceDemo 候选完成了登录、排序、最低价两件加购、收货信息填写和 Finish。汇总为 **17.98 / 1.44 / 19.42**，排序一次成功。17 条任务命令包含一次 agent 误用旧购物车引用的失败，随后使用已返回的新引用恢复。之后的链接标题修复确认六个商品按钮直接带价格；这次补测只验证登录与商品观察，没有冒充又完成一遍结账。

最新交互改进在本地完整浏览器 E2E 中 **110 项通过、0 失败**；[最终功能提交的完整跨平台 CI](https://github.com/leeguooooo/chrome-use/actions/runs/34266288931) 通过。此前 iframe、自定义控件计数和拖拽用例的失败已保留在详细记录中，未从成本或结论中删除。

这些测试证明修复覆盖了相应场景。它们不证明所有网页都能被可靠操作，也不证明账号身份正确。比较真实登录态时，必须核对实际 profile 与网站账号。

## 后续验收

v1.5.111 下载包仍需完成安装与浏览器回归，扩展 0.5.22 仍需商店交付。后续对照应使用匹配的浏览器配置、相同模型与任务，分别记录冷启动和预热后的运行；同时保留失败、补查、恢复和中途停止的成本。优先看任务完成率及恢复步骤，再看往返数、输出大小和耗时。
